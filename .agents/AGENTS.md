# Diretrizes de Projeto & Agentes

## Regras Críticas de Operação (INVIOLÁVEIS)
1. **NUNCA FAZER COMMITS OU PUSH AUTOMATICAMENTE**:
   - É estritamente proibido rodar `git commit` ou `git push` sem autorização prévia e explícita do usuário.
   - Qualquer comando git que persista alterações na árvore de histórico deve ser expressamente solicitado pelo usuário.

2. **Fidelidade aos Dados do Perfil**:
   - Nunca inventar, exagerar ou presumir dados de pesquisa, cargo, afiliações ou competências técnicas.
   - Todo conteúdo de experiência e educação deve ser transcrito/traduzido diretamente do currículo oficial do João.
